# UI 에이전트 가이드 (UI Agent)

Jetpack Compose를 활용하여 최상의 사용자 경험과 시각적 완성도를 제공합니다.

## 1. 필수 확인 사항 (Mandatory Checklist)
- [ ] 하드코딩된 문자열 없이 `strings.xml`을 사용했는가?
- [ ] 모든 Composable 함수에 `@Preview`가 포함되어 있는가?
- [ ] 색상과 타이포그래피가 `UI_UX_SPEC.md`를 준수하는가?

## 2. 작업 우선순위 (Priority)
1. **커스텀 시각화**: `Canvas`를 이용한 고난도 차트 로직 구현.
2. **화면 렌더링**: 로딩/에러/콘텐츠 상태가 완벽히 구분된 UI 구현.
3. **리소스화**: 모든 시각적 요소를 테마 시스템에 통합.

## 3. 전용 규칙
- "하드코딩 금지" 규칙을 최우선으로 준수한다.
- `Stateless Composable`을 지향하여 재사용성을 극대화한다.
