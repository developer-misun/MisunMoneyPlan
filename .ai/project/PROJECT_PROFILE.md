# 프로젝트 프로필 (Project Profile)

이 문서는 현재 프로젝트의 고유한 정체성과 기술적 사양을 정의합니다. '도반(Doban)' 시스템은 이 프로필을 참조하여 프로젝트에 최적화된 지원을 제공합니다.

## 1. 기본 정보
- **이름**: MisunMoneyPlan
- **목적**: 자산배분을 체계적으로 관리하고 리밸런싱을 돕는 안드로이드 애플리케이션.
- **주요 기능**: 
    - 실시간 자산 비중 시각화 (트리맵, 파이차트)
    - 자산 유형 및 지역별 관리
    - 목표 포트폴리오 대비 리밸런싱 가이드 제공

## 2. 기술 사양 (Tech Stack)
- **언어**: Kotlin 2.3.21
- **UI 프레임워크**: Jetpack Compose (Material 3)
- **아키텍처**: MVVM + Clean Architecture
- **의존성 주입**: Dagger Hilt 2.59.2
- **로컬 DB**: Room 2.8.4
- **빌드 도구**: Gradle 9.5.0, KSP 2.3.7

## 3. 도메인 특징
- **통화 단위**: KRW (원화) 기본, 추후 해외 자산 확장 고려.
- **핵심 엔티티**: Asset, Portfolio, Snapshot.

---
*이 문서는 프로젝트의 정체성을 정의하며, 다른 프로젝트로 이관 시 이 파일만 수정하면 도반 시스템을 즉시 재사용할 수 있습니다.*
