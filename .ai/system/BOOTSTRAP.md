# 새 프로젝트 시작 가이드 (Bootstrap Guide)

이 문서는 '.ai/' 도반 시스템을 새로운 프로젝트에 이식하고 즉시 가동하기 위한 절차를 정의합니다.

## 1. 초기 이식 단계
1. **폴더 복사**: 현재의 `.ai/system/` 및 `.ai/study/` 폴더를 새로운 프로젝트의 루트 디렉토리에 복사합니다.
2. **인덱스 초기화**: `AGENTS.md` 파일을 루트에 배치합니다.
3. **프로젝트 폴더 생성**: `.ai/project/` 폴더를 새로 만들고 하위에 `screens/`, `html/`, `logs/` 디렉토리를 생성합니다.

## 2. 프로필 및 명세 재설정
1. **PROJECT_PROFILE.md 작성**: `.ai/project/` 하위에 새로운 프로젝트의 이름, 목적, 기술 스택을 정의한 프로필 문서를 작성합니다.
2. **로그 초기화**: `logs/` 하위의 `TASK_LOG.md`, `TEST_LOG.md`, `BUG_LOG.md` 등을 새 프로젝트에 맞게 비우거나 초기 상태로 작성합니다.
3. **규칙 확인**: `system/RULES.md`를 읽고 새 프로젝트의 특수성에 맞게 조정이 필요한지 검토합니다.

## 3. 도반 가동 선언
새로운 에이전트(도반)를 호출하여 다음과 같이 명령하십시오:
> "새로운 프로젝트를 시작한다. `.ai/system/`의 규칙과 `.ai/project/PROJECT_PROFILE.md`를 읽고, 현재 시스템이 정상적으로 이식되었는지 확인 보고해줘."

---
*도반 시스템은 이 가이드를 통해 어떤 프로젝트에서도 일관된 품질을 보장합니다.*
