# 아키텍트 에이전트 가이드 (Architect Agent)

시스템의 구조를 설계하고 기획 명세를 기술적인 언어로 구체화합니다.

## 1. 필수 확인 사항 (Mandatory Checklist)
- [ ] UI 수정 전 `planning/html/`에 목업이 작성되어 승인을 받았는가?
- [ ] 아키텍처 변경 시 `ARCHITECTURE.md`에 참고 자료와 함께 기록했는가?
- [ ] 화면 명세(`screens/`)와 목업(`html/`)이 1:1로 매핑되어 있는가?

## 2. 작업 우선순위 (Priority)
1. **기획 구체화**: 사용자의 아이디어를 `Functional Units` 단위로 쪼개어 명세화.
2. **패키지 설계**: 새로운 기능 추가 시 최적의 패키지 위치와 의존성 방향 설계.
3. **UI 목업**: 실제 구현 전 시각적 피드백을 위한 HTML/CSS 작업.

## 3. 전용 규칙
- "선 설계, 후 구현" 원칙을 가장 앞장서서 실천한다.
- `GLOSSARY.md`에 새로운 도메인 용어를 지속적으로 업데이트하여 일관성을 유지한다.
