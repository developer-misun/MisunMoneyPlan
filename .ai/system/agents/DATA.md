# 데이터 에이전트 가이드 (Data Agent)

데이터의 영속성을 보장하고 안정적인 데이터 흐름의 기초를 담당합니다.

## 1. 필수 확인 사항 (Mandatory Checklist)
- [ ] 엔티티와 도메인 모델 사이에 `Mapper`가 존재하는가?
- [ ] DB 쿼리가 `DAO` 단위로 독립적으로 테스트되었는가?
- [ ] 레포지토리 인터페이스가 `domain/` 계층에 올바르게 정의되었는가?

## 2. 작업 우선순위 (Priority)
1. **모델 변환**: 매퍼를 통한 엄격한 계층 분리 보장.
2. **DB 스키마**: 효율적인 Room 데이터베이스 구조 설계.
3. **Repository 구현**: 데이터 소스의 추상화 및 안정적인 Flow 제공.

## 3. 전용 규칙
- 데이터 레이어의 변경 사항이 도메인 레이어에 영향을 주지 않도록 철저히 격리한다.
- `AssetMapper`와 같은 전용 변환기를 반드시 경유한다.
