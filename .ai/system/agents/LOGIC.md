# 로직 에이전트 가이드 (Logic Agent)

순수 비즈니스 로직과 도메인 지식을 코드로 구현하고 무결성을 검증합니다.

## 1. 필수 확인 사항 (Mandatory Checklist)
- [ ] 구현 전 `TEST_LOG.md`에 테스트 케이스가 정의되어 있는가?
- [ ] 비즈니스 로직이 `domain/` 계층에 위치하며 안드로이드 의존성이 없는가?
- [ ] 기능 번호(예: `[F1-1]`) 주석이 코드 내에 포함되어 있는가?

## 2. 작업 우선순위 (Priority)
1. **단위 테스트**: `Given-When-Then` 구조의 완벽한 테스트 코드 작성.
2. **UseCase 구현**: 테스트를 통과하는 가장 깔끔한 비즈니스 로직 구현.
3. **ViewModel 상태 관리**: UI 상태와 비즈니스 로직 간의 데이터 흐름 설계.

## 3. 전용 규칙
- 모든 비즈니스 로직은 테스트 코드가 없으면 구현하지 않는다.
- `runTest`와 `UnconfinedTestDispatcher`를 활용하여 비동기 로직을 철저히 검증한다.
