# SCR-04: TypeDetailScreen (유형별 상세 리스트)

특정 자산 유형(예: 주식, 현금)에 속한 모든 종목을 모아보는 화면입니다.

## 📋 기능 명세 (Functional Units)

- **`[F4-1]` 유형별 요약**: 해당 유형의 총 자산 규모 및 전체 대비 비중 노출.
- **`[F4-2]` 소속 종목 리스트**: 해당 유형에 포함된 모든 종목의 리스트 (`AssetList` 재사용).

## 🎨 UI/UX 디자인 가이드

### 레이아웃 구성
- **TopBar**: 선택된 유형 이름(예: "주식") 표시.
- **Header Section**: 유형 총액 정보 및 미니 파이 차트.
- **List Section**: `SCR-01`의 종목 리스트와 동일한 UI 사용.
