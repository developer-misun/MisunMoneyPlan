# 스토리보드 및 상세 기능 명세 (Detailed Storyboard)

## 🗺️ 전체 화면 맵 및 상세 기능 (Screen Map & Functions)

### 1. HomeScreen (메인 대시보드)
사용자의 실시간 자산 배분 현황을 시각화하고 관리하는 메인 화면입니다.

#### [공통 영역]
- **`[F1-1]` 총 자산 요약**: 전체 자산 합계 표시 (KRW 포맷).
- **`[F1-2]` 메인 탭 네비게이션**:
    - **종목별 / 유형별 / 지역별** 자산 분포 확인을 위한 탭 전환.
- **`[F1-3]` 네비게이션 액션**:
    - **자산 추가 (FAB)**: 신규 자산 입력 다이얼로그 호출.
    - **포트폴리오 관리 버튼 (TopBar)**: 클릭 시 `PortfolioScreen`으로 이동 (별도 화면).

#### [종목별 탭 (By Stock)]
- **`[F1-4]` 종목별 트리맵 차트**: 비중에 따른 사각형 면적 시각화.
- **`[F1-5]` 상위 종목 리스트**: 금액순 정렬 리스트 (클릭 시 `StockDetailScreen` 이동).

#### [유형별 탭 (By Type)]
- **`[F1-6]` 유형별 파이 차트**: 자산 유형(현금, 주식, 코인 등) 비율 시각화.
- **`[F1-7]` 자산 유형 리스트**: 유형별 합계 및 비중 표시 (클릭 시 `TypeDetailScreen` 이동).

#### [지역별 탭 (By Location)] - *NEW (TODO 반영)*
- **`[F1-8]` 지역별 차트/리스트**:
    - 국내/국외 속성에 따른 자산 배분 시각화.
    - 지역별 총액 및 비중 표시.

### 2. PortfolioScreen (포트폴리오 관리) - *NEW (별도 화면 분리)*
목표 자산 배분을 설정하고 현재 상태와 비교하여 리밸런싱을 돕는 화면입니다.

- **`[F4-1]` 포트폴리오 목록**: 생성된 포트폴리오(이름, 목표 합계 등) 리스트.
- **`[F4-2]` 리밸런싱 가이드**: 
    - 특정 포트폴리오 선택 시 **목표 비중 vs 현재 비중** 비교 차트 노출.
    - 목표 달성을 위해 필요한 매수/매도 금액 자동 계산 표시.
- **`[F4-3]` 스냅샷 기능**: 현재 자산 배분 상태를 해당 포트폴리오의 비교값으로 저장.

### 3. StockDetailScreen (종목 상세 및 편집)
- **`[F2-1]` 자산 정보 편집**: 종목명, 금액, 유형, **지역(국내/국외)**, 메모.
- **`[F2-2]` 삭제 및 저장**: 데이터베이스 연동.
